# JavaScript Problem-Solving Assignment

A collection of five JavaScript challenges focused on core programming fundamentals, logical reasoning, and practical problem-solving.

## Key Features

* **Value Analyzer** — Identifies data types and truthy/falsy values.
* **Day Classifier** — Determines weekends and working days.
* **Username Validator** — Validates usernames against defined rules.
* **CNG Fare Calculator** — Calculates fares based on distance, waiting time, and night charges.
* **Cricket Chase Analyzer** — Evaluates chase difficulty using the required run rate.

## Technologies

* JavaScript (ES6+)
* Functions and conditional logic
* String methods and operators
* Default parameters

## Purpose

Strengthen JavaScript fundamentals through practical coding exercises and improve logical thinking and problem-solving skills.
